# HTML-Only Layout Task

## What is this task?
This project is an HTML assignment designed to practice building core web layouts using **pure HTML only**. Per the assignment constraints, **no CSS** (external, internal, or inline style attributes) is used to implement the structures shown in the specifications, relying entirely on semantic HTML tags and native attributes.

The project is split across three dedicated HTML pages:
1. **Form Page (`form.html`)**: An application form containing various text fields, date pickers, number counters, dropdown select menus, radio buttons, checkboxes, password fields, and action buttons.
2. **List Page (`list.html`)**: A collection of structured lists showcasing descending ordered lists starting from a custom number, nested unordered list items, and multi-tier mixed lists (ordered nesting inside unordered structures).
3. **Table Page (`table.html`)**: A structured data grid demonstrating advanced table layouts utilizing cell padding, border settings, horizontal column-skipping (`colspan`), vertical row-skipping (`rowspan`), and pure HTML background coloring attributes.
